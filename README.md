👉 https://urbannest-7oez.onrender.com/listings
## ✨ Features

- 🔍 Search listings by country
- 🏡 Create, edit, and delete listings
- 📸 Upload images (Cloudinary)
- ⭐ Add reviews and ratings
- 🔐 User authentication (login/signup)
- 🗺️ Map integration (Leaflet)

## 🛠️ Tech Stack
- Frontend: HTML, CSS, Bootstrap, EJS
- Backend: Node.js, Express.js
- Database: MongoDB
- Image Storage: Cloudinary
- Maps: Leaflet
- Deployment: Render
  ## ⚙️ Installation

1. Clone repo
git clone https://github.com/the2rivage/UrbanNest.git

2. Install dependencies
npm install

3. Create .env file and add:
CLOUDINARY_URL=your_key
MONGO_URL=your_db

4. Run app
node app.js
## 🔐 Environment Variables

- CLOUDINARY_URL
- MONGO_URL
- SESSION_SECRET
